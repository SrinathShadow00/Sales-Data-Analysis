# Sales-Data-Analysis
Analyzed 9,000+ Superstore sales records using SQL and SQLite to identify top-performing products, revenue trends, and regional sales performance.  Used aggregations, CTEs, date functions, and profit margin analysis to identify seasonal trends, unprofitable product categories, and high-revenue regions.

Exploratory analysis of a **9,500-row retail sales dataset** (4,452 orders, 112 products,
900 customers, 2021–2024) using pure SQL in SQLite. The project answers four business
questions: which products drive revenue, how revenue moves over time, where the business
loses money, and how performance differs by region and category.
