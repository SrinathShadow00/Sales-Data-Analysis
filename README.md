# Sales-Data-Analysis
Analyzed 9,000+ Superstore sales records using SQL and SQLite to identify top-performing products, revenue trends, and regional sales performance.  Used aggregations, CTEs, date functions, and profit margin analysis to identify seasonal trends, unprofitable product categories, and high-revenue regions.

• Analyzed 9,000+ Superstore sales records using SQL to identify top-performing products, contributing to insights on revenue
drivers.
• Leveraged aggregations, CTEs, and date functions to track monthly revenue trends, uncovering seasonal peaks for strategic
forecasting.
• Identified losses from unprofitable products by calculating profit margins across categories and sub-categories.
• Optimized business insights by segmenting sales by region and category, highlighting the West region as the highest revenue
generator.
